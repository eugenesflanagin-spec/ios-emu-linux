First release of ready-made **Arch Linux packages** for the three iOS emulators in this repo. You no longer have to
compile QEMU yourself: install a package, put your own files in the folder it tells you, and start it from the menu.

## What's in this release

| File | What it is |
|---|---|
| `qemu-apple-t8030-git-…-x86_64.pkg.tar.zst` | **iPhone 11, iOS 14.** An unofficial build of [ChefKiss Inferno](https://github.com/ChefKissInc/Inferno) (QEMU 10.2 based). Command `qemu-apple-t8030`, menu entry "QEMU t8030". Middle click = Home button. Your own boot splash with `qemu-apple-t8030-set-boot-splash`. |
| `qemu-ios-ipod-git-…-x86_64.pkg.tar.zst` | **iPod touch 1st generation, iPhoneOS 1.0**, on [devos50/qemu-ios](https://github.com/devos50/qemu-ios). Command `ipod-touch-qemu`, menu entry "iPod touch 1G". Sets Auto-Lock to Never by itself and runs the NAND from RAM. |
| `xnu-qemu-arm64-git-…-x86_64.pkg.tar.zst` | **iOS 12.1 text shell** (iPhone 6s Plus) on [Aleph Security's xnu-qemu-arm64](https://github.com/alephsecurity/xnu-qemu-arm64), with this repo's Linux-host fixes (correct console colours, working SSH tunnel). Commands `xnu-qemu-ios`, `xnu-qemu-ios-console`, `xnu-qemu-ios-ssh`. |
| `*.src.tar.gz` | The recipe (PKGBUILD) and small files for each package, the same as on the AUR. |
| `SHA256SUMS` | Fingerprints to check your downloads. |

The same three packages are on the AUR: `qemu-apple-t8030-git`, `qemu-ios-ipod-git`, `xnu-qemu-arm64-git`.

## Install

Download the package(s) you want and `SHA256SUMS` into one folder, then in that folder:

```
sha256sum -c SHA256SUMS --ignore-missing
sudo pacman -U ./qemu-apple-t8030-git-*.pkg.tar.zst
```

Or with an AUR helper: `yay -S qemu-apple-t8030-git` (this compiles it on your PC).

Each package installs into its own folder under `/opt`, so it sits beside your normal `qemu` and doesn't replace it.
Run the command once: it tells you which files it needs and where to put them. The full walkthrough is in
[GUIDE.md](https://github.com/eugenesflanagin-spec/ios-emu-linux/blob/main/GUIDE.md), section 3.

## Important

- **No Apple files are included or downloaded**: no firmware, keys, SEP ROM or disk images. You prepare them
  yourself from Apple's own servers, following each emulator's guide. Please don't share yours.
- The iPhone 11 package is **not an official Inferno build** and isn't endorsed by ChefKiss. As their branding
  notice asks, it ships without their artwork and name. Set it up with their guide:
  <https://chefkiss.dev/applehax/inferno/>.
- Built in a clean Arch Linux container with Arch's standard compiler settings (generic x86-64), and each package
  was install-tested in another fresh container. Needs an x86-64 PC running Arch or an Arch-based distribution.
